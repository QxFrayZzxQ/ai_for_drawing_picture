# ai_for_drawing_picture
ai_for_drawing_picture

Телеграм-бот на Python, который распознает эмоции на фотографиях с помощью нейросети

## Возможности
- Прием изображений от пользователей через Telegram
- Распознавание эмоций с помощью обученной модели Keras
- Возврат результата с процентом уверенности и индивидуальным советом в зависимости от эмоции

## Использование
- Python 3.10+
- pyTelegramBotAPI (telebot)
- TensorFlow / Keras
- NumPy
- Pillow (PIL)

## Структура 
bot_face/
- logic.py         # Модуль подготовки и обработка изображение с помощью нейросети
- main.py          # Основной файл запуска Telegram-бота
- keras_model.h5   # Обученная модель
- labels.txt       # Список классов 
- config.py        # Файл с вашим токеном
- README.md        # Документация проекта
